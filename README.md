# Автоматизированный пайплайн детекции электросамокатов компании «Лайт»

## О проекте

Проект представляет собой экспериментальный пайплайн компьютерного зрения для автоматизированной обработки фотографий, поступающих в службу поддержки сервиса аренды электросамокатов.

Основная задача системы — определить, относится ли электросамокат на фотографии к компании «Лайт», обнаружить серийный номер и распознать его для последующей проверки по внутренней базе данных.

Проект ориентирован на обработку **статических изображений**, предоставляемых пользователями сервиса, и не предназначен для анализа видеопотока или детекции движущихся объектов.

---

## Назначение

Пайплайн позволяет автоматизировать первичную обработку пользовательских фотографий и сократить объем ручной работы операторов службы поддержки.

Основные задачи системы:

- обнаружение электросамоката на изображении;
- определение принадлежности самоката к компании «Лайт»;
- локализация области с серийным номером;
- подготовка изображения номера к распознаванию;
- извлечение серийного номера при помощи OCR;
- дальнейшая возможность проверки номера по базе данных.

---

## Общая схема работы

```
          Исходное изображение
                    │
                    ▼
         Детекция электросамоката
              (YOLOv11 Detector)
                    │
                    ▼
        Обрезка найденного объекта
                    │
                    ▼
      Цветовая сегментация (HSV)
                    │
         Самокат компании «Лайт»?
             │                 │
            Нет               Да
             │                 ▼
        Завершение      Детекция серийного номера
                           (YOLOv11)
                                │
                                ▼
                    Выделение области номера
                                │
                                ▼
                         OCR (EasyOCR)
                                │
                                ▼
                  Получение серийного номера
                                │
                                ▼
              Возможность проверки по базе данных
```

## Используемые методы

### Детекция объектов

Для поиска электросамокатов и области серийного номера используются две независимо обученные модели **YOLOv11**.

### Цветовая сегментация

При помощи преобразования изображения в цветовое пространство **HSV** анализируются фирменные цвета компании «Лайт», что позволяет исключить самокаты других операторов аренды.

### OCR

После локализации области серийного номера выполняется распознавание текста с использованием **EasyOCR**.

## Архитектура пайплайна

Пайплайн включает несколько последовательно выполняемых этапов:

1. Загрузка изображения.
2. Детекция электросамоката.
3. Обрезка найденного объекта.
4. Проверка фирменной цветовой схемы.
5. Детекция области с серийным номером.
6. Выделение изображения номера.
7. OCR-распознавание.
8. Получение серийного номера.
9. Очистка временных файлов.

- зависимости проекта;

Проект может быть расширен следующими возможностями:

## Применение

Разработанный пайплайн демонстрирует пример применения методов компьютерного зрения для автоматизации бизнес-процессов службы поддержки.

Использование подобного решения позволяет существенно сократить время обработки пользовательских обращений и минимизировать объем ручной проверки фотографий.
